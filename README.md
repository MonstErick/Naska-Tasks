# 🐾 Naska Tasks

### Organiza tus tareas, una a una.

Naska Tasks es una aplicación web creada como parte del ABP4. Su objetivo es permitir crear y administrar tareas de una manera sencilla, indicando una descripción y una fecha límite para cada una.

El proyecto fue desarrollado utilizando JavaScript y los diferentes contenidos aprendidos durante el módulo.

---

## ✨ Funcionalidades

Naska Tasks permite:

- ➕ Crear nuevas tareas.
- ✏️ Editar tareas existentes.
- 🗑️ Eliminar tareas.
- 🔄 Cambiar el estado de las tareas.
- 📅 Registrar la fecha de creación y fecha límite.
- ⏳ Mostrar un contador con el tiempo restante para cada tarea.
- ⏸️ Detener el contador cuando una tarea se encuentra completada.
- 💾 Guardar las tareas utilizando `localStorage`.
- 🔄 Recuperar las tareas después de actualizar la página.
- 🌐 Obtener y enviar información mediante una API.
- 📱 Utilizar una interfaz adaptable a diferentes tamaños de pantalla.
